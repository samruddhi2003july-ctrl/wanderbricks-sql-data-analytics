# Wanderbricks – SQL Data Analytics Project

## 1. Project Overview

Wanderbricks is a SQL Data Analytics project focused on analyzing booking and property-related business data using **Databricks SQL**.

The project involves exploring a dataset consisting of 9 tables to understand business performance, identify trends, evaluate revenue, and generate meaningful insights.

SQL queries are used to analyze key business areas, including bookings, revenue, properties, hosts, cities, cancellation rates, and property amenities.

The objective is to transform raw data into meaningful business insights that can support data-driven decision-making.

## 2. Business Objectives

The main objectives of this project are:

- Analyze overall business performance using key business KPIs.
- Evaluate total revenue and booking trends.
- Understand property performance and distribution.
- Analyze host performance and property listings.
- Identify cities contributing to business activity.
- Calculate and analyze booking cancellation rates.
- Explore property amenities and their distribution.
- Identify business trends and opportunities for improvement.

## 3. Dataset Description

5. Verify the table structures and column names.
